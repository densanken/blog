はじめに

こんにちは，駄文を書き連ねる偽大学生 a.k.a. gotoです．

皆さんはNOTとかORのIC買ったつもりでNANDだけ大量に買った経験はありませんか?

「よ～し買い物から帰ってきたぞ～～～！！」

NANDで工夫する

まず，前提知識として，NOT(¬\lnot¬)，OR(∨\lor∨)，AND(∧\land∧)をいくつも組み合わせれば，あらゆる入出力はわりかしシンプルに表現できます． 加法標準形とか乗法標準形とか言うやつです． つまり，NANDのみでこの3つを作ることができればミッションコンプリートですね．

(実際は，NOTとANDかORがあれば，ド・モルガンの法則で使ってないほうも作れるので別に3つ作る必要はないんですが)

NANDは↑\uparrow↑か∣\mid∣(シェファーの棒記号というらしい)という記号で表されます．
今回は

天啓により∣\mid∣を採用します．

結論，

¬A=A∣AA∧B=(A∣B)∣(A∣B)A∨B=(A∣A)∣(B∣B)\lnot A = A \mid A\\ A \land B = (A \mid B) \mid (A \mid B)\\ A \lor B = (A \mid A) \mid (B \mid B)¬A=A∣AA∧B=(A∣B)∣(A∣B)A∨B=(A∣A)∣(B∣B)

で行けます．

これが本当に動作すればNANDだけですべてを表現できますね

パパっと確認してみましょう

よく観察してみる(式変形)

真理値表とかを書かなくてもよく観察すると，NOTさえわかればANDとORはすぐにわかると思います．

AND

まず，NANDは

A∣B=¬(A∧B)A \mid B = \lnot(A \land B)A∣B=¬(A∧B)

なので，同じものを2つ並べた X∣XX \mid XX∣X を NOT(¬X\lnot X¬X)と認めれば， ANDは

(A∣B)∣(A∣B)=¬(A∧B)∣¬(A∧B)=¬¬(A∧B)=(A∧B)\begin{aligned} (A \mid B) \mid (A \mid B) &= \lnot(A \land B) \mid \lnot(A \land B)\\ &= \lnot\lnot(A \land B)\\ &= (A \land B) \end{aligned}(A∣B)∣(A∣B)​=¬(A∧B)∣¬(A∧B)=¬¬(A∧B)=(A∧B)​

と変形できます．

OR

ORは

(A∣A)∣(B∣B)=¬A∣¬B=¬(¬A∧¬B)=(¬¬A∨¬¬B)=(A∨B)\begin{aligned} (A \mid A) \mid (B \mid B) &= \lnot A \mid \lnot B\\ &= \lnot(\lnot A \land \lnot B)\\ &= (\lnot\lnot A \lor \lnot\lnot B)\\ &= (A \lor B) \end{aligned}(A∣A)∣(B∣B)​=¬A∣¬B=¬(¬A∧¬B)=(¬¬A∨¬¬B)=(A∨B)​

です．2行目から3行目の変形はド・モルガンの法則です．

¬(A∧B)=(¬A∨¬B)¬(A∨B)=(¬A∧¬B)\begin{aligned} \lnot(A \land B) &= (\lnot A \lor \lnot B)\\ \lnot(A \lor B) &= (\lnot A \land \lnot B) \end{aligned}¬(A∧B)¬(A∨B)​=(¬A∨¬B)=(¬A∧¬B)​

これです．
多分どこかで聞いたことがあると思います．詳しく知りたかったらググってください．
