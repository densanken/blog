Markdown

言語を md または markdown にしたコードブロックは、上部のタブで「Markdown」（コード）と「プレビュー」（レンダリングした表示）を切り替えることができます。 ただし、常に最初はコードの表示となります。 なお、コピーボタンではどちらの表示であっても元の Markdown がコピーされます。

プレビューでは、GitHub Flavored Markdown（表、タスクリスト、取り消し線、脚注、URL の自動リンク）、GitHub Alerts、数式、シンタックスハイライト付きのコードブロックが使えます。 コードブロックを含める場合は、外側のコードブロックを 4 つ以上の ` で囲んでください。 一方で、安全のため、次のものはレンダリングされません。

  • 画像（代替テキストだけが表示されます）
  • HTML のタグ
  • 埋め込みとリンクカード（URL は通常のリンクになります）
  • アイコンなどの MDC の記法と、絵文字のショートコード（そのままの文字で表示されます）
  • Mermaid や PlantUML の図（コードのまま表示されます）

また、プレビューの中の見出しは、記事の見出しと同じ大きさで表示されますが、目次には含まれません。
